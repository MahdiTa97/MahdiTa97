## What I do

I work with startups and product teams that need a React front end they can actually
ship on and keep shipping. Most of my work falls into one of these:

- **Product front ends** — dashboards, admin panels, customer-facing apps
- **Design systems** — shared component packages that stay consistent as teams grow
- **Frontend architecture** — monorepos, build pipelines, CI/CD, performance work
- **Tooling** — CLI scaffolders, dev-server config, small packages the team reuses
